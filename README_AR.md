# مولّد يوزرات ديسكورد وتيك توك وإنستغرام

## النشر على Render
1. أنشئ مستودعًا في GitHub.
2. ارفع ملفات هذه الحزمة إلى جذر المستودع: `index.html` و`discord_username_server.py` و`requirements.txt` و`render.yaml`.
3. اربط GitHub بحساب Render.
4. في Render اختر **New > Blueprint**، واختر المستودع ثم اضغط **Deploy Blueprint**.
5. بعد اكتمال النشر افتح رابط الخدمة الذي ينتهي بـ `onrender.com`.

## ملاحظات الفحص
- ديسكورد: يجري الموقع فحصًا تلقائيًا عبر واجهة غير موثّقة.
- تيك توك وإنستغرام: يفحص الموقع صفحة الاسم العامة تلقائيًا بالتتابع، بمعدل طلب واحد كل خمس ثوانٍ. النتيجة «ظهر حساب» أو «لم تظهر صفحة» أو «تعذر التأكد».
- عدم ظهور الصفحة لا يثبت أن الاسم متاح للحجز؛ قد يكون الاسم محجوزًا أو تمنع المنصة ظهوره. أكّد الأسماء داخل التطبيق.
- لا تدخل كلمة مرورك أو رموز تسجيل الدخول في الموقع.
